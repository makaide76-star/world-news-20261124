A front-page image summing up the world news of Tuesday 24 November 2026: Nvidia reinstating Jensen Huang as CEO after Trump's push, a possible Russian nuclear-armed satellite launch in December, leaked data putting Russian war dead near 500,000, Moscow warning Estonia it risks "open war", a false-alarm airspace scare on South Korea's Ulleung Island, Sheikh Hasina planning to return to Bangladesh on 16 December, two U.S. states suing Musk over Grok deepfakes, and the U.S. leading the 2031 Women's World Cup. The image is drawn by `tools/make_image.py` (Pillow, build time only) and `main.py` copies it to the output directory.

## Run it

```sh
python3 tools/make_image.py   # redraw assets/entry.png
python3 main.py               # writes entry.png to $MAKEFUN_OUTPUT_DIR (default /output)
```
